# README assets

Every image the root [`README.md`](../../../README.md) shows, at README size:
**≤ 600 KB and ≤ 1920 px wide**, which is what keeps a front page fast on a phone.

Nothing here is an original. Each file is a derivative of something else in the
repo, and the source is the thing to edit:

| File | Derived from |
|---|---|
| `hero-assembled.jpg`, `enclosure-angle.jpg`, `board-closeup.jpg`, `board-in-case.jpg`, `pcb-bare-stack.jpg` | the full-resolution photos in [`../`](../) (`IMG_*.jpg`), downscaled |
| `pcb-v0.7.1-top.png`, `pcb-v0.7.1-bottom.png` | [`../../../pcb/renders/`](../../../pcb/renders/), cropped to the board |
| `wiring-v5.5.png` | [`../../../versions/v5.5-power-filter/images/wiring-v5.5.png`](../../../versions/v5.5-power-filter/images/wiring-v5.5.png), which is itself generated by `tools/wiring_diagrams.py` |
| `poster.jpg` | [`../../poster/super-limon-piano-cartel.png`](../../poster/), which is kept **byte for byte** and hash-pinned — never re-encode that one in place |

So: change a render or a diagram at its source, re-run its generator, then
regenerate the copy here. A README asset is never the thing of record.
