# V2 hardware — keyboard test rig

Same keyboard as [V1](../v1-banana-piano/HARDWARE.md), minus the ultrasonic
module. Reconstructed from
[firmware/keyboard-test/keyboard-test.ino](firmware/keyboard-test/keyboard-test.ino).

## Pin map

| Pin | Direction | Role |
|---|---|---|
| A0–A6 | analog in | 7 fruit touch keys, each with a **220 Ω pull-up to +5 V** |
| D8 | out | speaker / passive buzzer (`tone()`, one note per key) |
| D0/D1 | UART | `Serial.print` of the raw A0/A1 readings (⚠️ `Serial.begin` is commented out) |
| 5V / GND | — | rails; the player holds a clip on **GND** |

D11, D12 and D13 are unused on this board — that is the whole hardware delta
against V1.

| Component | Qty | Notes |

## Sensing

Identical to V1 (pins biased high, touch drags them down), with a heavier
average:

```cpp
if (((analogRead(n) + analogRead(n) + analogRead(n) + analogRead(n)) / 4) <= 1019) { /* key n */ }
```

Keys 1–6 use 4 samples, key 7 uses 2. Full physics and the V4 polarity flip:
[../../docs/HARDWARE.md](../../docs/HARDWARE.md).
